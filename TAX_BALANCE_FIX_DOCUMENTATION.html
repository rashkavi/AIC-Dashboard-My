❌ The Problem (Before)

Tax was being calculated incorrectly by multiplying the paid amount by the tax rate:

WRONG FORMULA: tax = paid × (rate / 100) base = paid - tax Example: paid = 10,250, rate = 2.5% tax = 10,250 × 0.025 = 256.25 ❌ base = 10,250 - 256.25 = 9,993.75 ❌ This doesn't make sense because: 9,993.75 + 256.25 = 10,250 (works mathematically, but conceptually wrong) The issue: tax should be proportional to the BASE fee, not the total paid amount

✅ The Solution (After)

Tax is now correctly extracted from the tax-inclusive paid amount:

CORRECT FORMULA (Tax-Inclusive Model): factor = 1 + (rate / 100) base = paid ÷ factor tax = paid - base Example: paid = 10,250, rate = 2.5% factor = 1 + 0.025 = 1.025 base = 10,250 ÷ 1.025 = 10,000 ✓ tax = 10,250 - 10,000 = 250 ✓ Verification: 10,000 + 250 = 10,250 ✓ (Perfect!) Tax rate check: 250 ÷ 10,000 = 0.025 = 2.5% ✓

📝 Code Changes

1. Helper Function (Both Files)

A new function to extract tax correctly:

/** * Extract base and tax from a tax-inclusive paid amount * @param float $paid Tax-inclusive amount paid * @param float $rate Tax rate (e.g., 2.5) * @return array ['base' => base_amount, 'tax' => tax_amount] */ function extractTaxFromPaid($paid, $rate) { if ($rate <= 0 || $paid <= 0) return ['base' => $paid, 'tax' => 0]; $factor = 1 + ($rate / 100); $base = $paid / $factor; $tax = $paid - $base; return ['base' => round($base, 4), 'tax' => round($tax, 4)]; }

2. Processing Only When Approved

Taxes and penalties are now only processed when payment status is changed to 3 (Approved):

if ($newStatus == 3 && $taxRate > 0) { // Only when approving: extract tax from paid amount $extracted = extractTaxFromPaid($paidAmountBase, $taxRate); $paidAmountBase = $extracted['base']; // Update to base amount $taxAmountBase = $extracted['tax']; // Extracted tax amount } else { // If not approving or no tax rate, tax is 0 $taxAmountBase = 0; }

3. Penalty Processing

Penalties are inserted into the database ONLY when payment is approved:

// INSERT penalty_payments table if penalty amount > 0 // ✅ ONLY WHEN APPROVED (status = 3) if ($penaltyAmountLKR > 0 && $newStatus == 3) { Database::iud("INSERT INTO `panelty_payments` ..."); }
